## 中文

NextStep 是一个通用 Agent Skill：把复杂任务变成离线行动图，先突出下一步，需要时展开全图。每步都有完成标准和前置依赖，你可以标记完成、记录阻塞，并导出进度下次继续。

代码、界面和学习卡片示例均为原创，采用 MIT 许可证。无需账号或服务器，不自动执行任务，不宣称治疗 ADHD。真实计划和进度请保持私密。

仓库：https://github.com/Amossse/nextstep

## English

NextStep is a portable Agent Skill that turns an approved task into an offline action map. Focus on
one next action, expand the full path, mark completion, record blockers and export progress to resume.
Original code, UI and fictional examples; MIT licensed. No account, server, task execution or medical
efficacy claim. Keep real plans and progress private.

Repository: https://github.com/Amossse/nextstep
